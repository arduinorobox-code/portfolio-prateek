# Prateek Haritwal — Personal Portfolio

A simple, responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — page structure and content
- `style.css` — all styling, including mobile responsiveness
- `script.js` — mobile menu behaviour
- `hardware-workbench.jpg` — hero image

## Upload to GitHub

1. Create a new repository on GitHub (e.g. `portfolio`).
2. Upload all four files (keep them in the same folder, no subfolders).
3. Commit the changes.

## Publish with GitHub Pages (optional)

1. In your repository, go to **Settings → Pages**.
2. Under **Source**, choose **Deploy from a branch**, select the `main` branch and the `/ (root)` folder, then save.
3. Your site will be live in a minute or two at `https://<your-username>.github.io/portfolio/`.
